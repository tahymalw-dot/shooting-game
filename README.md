# Legend Shooter — CS2 Mobile Edition (v0.3) — HANDOFF README

## الهدف النهائي
لعبة شوتر تكتيكية 3D بمستوى CS2 للجوال والكمبيوتر:
- رسوم وخرائط 3D مصممة بالكود (تخطيط تكتيكي على غرار Dust2 / Arena مع ممرات، جسور/منصات، ساحة وسطى، مواقع قنص، وتغطية)، خامات إجرائية عالية الدقة (`CanvasTexture`) للجدران والأرضية والصناديق، وسماء ديناميكية (`Skybox`).
- ذكاء اصطناعي متقدم للأعداء (`A* Pathfinding` + البحث عن تغطية خلف الصناديق + تفادي التداخل + فئات أعداء متعددة مع شريط صحة فوق كل عدو).
- ترسانة أسلحة CS2 كاملة مع نماذج 3D مفصلة لكل سلاح، منظار تقريب للقناص (`Scope Zoom`)، ارتداد (`Recoil`)، ثقوب رصاص على الجدران، جزيئات شرر ودم، وقائمة شراء (`Buy Menu`) على غرار CS2.
- تغليف أندرويد أصلي (`Android Native WebView APK Project` + `GitHub Actions Auto-APK Builder`) لتوليد ملف `.apk` حقيقي جاهز للتثبيت على الجوال بنقرة واحدة (سواء محلياً عبر Gradle أو تلقائياً عبر السحابة مجاناً بدون تثبيت Android Studio).

## التقنية
- **محرك اللعب**: HTML5 + JavaScript (ES Modules) + **Three.js r128**.
- **تغليف التطبيق الحقيقي (`APK`)**:
  1. مجلد `android-native-app/`: مشروع Android Studio / Gradle كامل بلغة Java (`MainActivity.java` مع WebView ملء الشاشة Fullscreen Immersive، قفل الاتجاه الأفقي `landscape`، وتسريع العتاد `Hardware Acceleration`) جاهز للبناء مباشرة `./gradlew assembleDebug` أو عبر Android Studio.
  2. ملف `.github/workflows/build-apk.yml`: بناء تلقائي سحابي يولّد لك ملف `Legend-Shooter.apk` جاهز للتحميل مباشرة على جوالك بمجرد رفع المجلد على GitHub (بدون الحاجة لأي برامج على جهازك!).

## الموجود حاليا (v0.3 - CS2 Tactical Overhaul & Native Android APK)
1. **خريطة تكتيكية مصممة على غرار CS2 (`js/world.js`)**:
   - ممرات جانبية (`Long A`, `Mid`, `Tunnel B`)، ساحة وسطى، صناديق تغطية تكتيكية، جدران إسمنتية وخشبية بخامات إجرائية مولّدة بالكود (`CanvasTexture`)، سماء متدرجة (`Skybox`)، وإضاءة وظلال واقعية.
   - بورتات تكتيكية متطورة مع حلقات طاقة دوّارة وتأثير انتقال فوري.
2. **ترسانة أسلحة CS2 ونماذج 3D مفصلة (`js/weapons.js`)**:
   - `Glock-18` (مسدس تكتيكي)، `MP9 SMG` (رشاش سريع)، `AK-47` (بندقية هجومية عالية الضرر)، `Nova Shotgun` (شوتقن)، و`AWP Sniper` (قناص مع منظار تقريب حقيقي `2.5x Scope`).
   - ارتداد بصري وحركي، وميض فوهة، ثقوب رصاص (`Bullet Decals`) على الجدران، وجزيئات شرر ودم (`Particles`).
   - صوتيات احترافية مولّدة بالكود (`WebAudio Synthesizer`) لكل سلاح وللإصابات والـ Headshot.
3. **ذكاء اصطناعي تكتيكي للأعداء (`js/enemies.js`)**:
   - شبكة ملاحة (`Grid A* Pathfinding`) لتجاوز الجدران والصناديق بذكاء وعدم التعلق بها.
   - سلوك تغطية (`Cover Seeking`) عندما تنخفض صحة العدو، وتباعد بين الأعداء (`Separation Steering`).
   - شريط صحة عائم فوق كل عدو، وأنيميشن مشي وإطلاق نار، وفئات (`Soldier`, `Rusher`, `Heavy Tank`, `Sniper`).
4. **واجهة وتجربة CS2 + تحكم جوال احترافي (`js/mobile.js`, `js/ui.js`)**:
   - قائمة شراء دائرية/بطاقات على غرار CS2 (`B` أو زر المتجر)، سجل القتل (`Kill Feed`) أعلى اليمين، مؤشر إصابة `X` مثل CS2، عداد نقود `$`، وأعلى نتيجة محفوظة في `localStorage`.
   - تحكم جوال متكامل: عصا حركة يسارية، منطقة تصويب يمنى مع زر إطلاق عائم للتصويب والإطلاق معاً، زر منظار القناص `Scope`، قفز، تعبئة، وتبديل السلاح.
5. **تطبيق أندرويد حقيقي (`android-native-app/` + `.github/workflows/build-apk.yml`)**:
   - مشروع أندرويد أصلي (`Android Gradle Project`) جاهز لبناء `.apk` حقيقي بدون متصفح.

## أخطاء معروفة
- بيئة الخادم السحابي لا تحتوي على `Android SDK` لتجميع ملف `.apk` ثنائي مباشرة أثناء المحادثة، لذا تم بناء مشروع Android Studio/Gradle أصلي متكامل (`android-native-app/`) + ملف بناء سحابي تلقائي (`GitHub Actions`) يولّد الـ `.apk` فوراً عند الرفع.
- تحميل مكتبة `Three.js` يتم من CDN حالياً؛ يُفضل مستقبلاً تضمين نسخة محلية داخل `assets/vendor/three.min.js` ليعمل التطبيق 100% أوفلاين بدون إنترنت.
